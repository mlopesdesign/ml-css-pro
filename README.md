# ML CSS Pro

Plugin comercial WordPress para gestão visual de CSS — ML Lopes Design.

Editor visual de CSS para WordPress e Nicepage, com scanner de CSS do frontend, detecção real de seletores, editor de código com realce de sintaxe, validação de CSS, biblioteca de snippets, histórico com restauração e assistente de seletores.

## Versão atual: 1.6.0

## Instalação

Baixe o ZIP da [última release](https://github.com/mlopesdesign/ml-css-pro/releases/latest) e faça upload em `Plugins > Adicionar novo > Upload`.

## Compatibilidade

- WordPress 6.0+ (testado até 6.8)
- PHP 8.1+ (este plugin requer PHP 8.1+)
- Auto-update via GitHub nativo (sem token)
