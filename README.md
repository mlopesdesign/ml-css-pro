# ML CSS Pro

Editor visual de CSS para WordPress e Nicepage por ML Lopes Design.

## Recursos

- Paletas, fontes, botoes, header, rodape, formularios
- - Editor de codigo com CodeMirror (realce, lint, expandir)
  - - Snippets CSS prontos para uso
    - - Historico de revisoes com restauracao
      - - Assistente de seletores Nicepage
        - - Cache CSS compilado em uploads/ml-css-pro/compiled.css
          - - Licenciamento integrado
            - - Atualizador automatico via GitHub
             
              - ## Instalacao
             
              - Baixe o ZIP da ultima release e instale via WordPress > Plugins > Adicionar Novo > Upload.
